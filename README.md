# HTML and CSS Tutorial

Folders are numbered in lesson order. Start at 01 and continue down the list; the earliest foundations come first. In the exercise folders, HTML and CSS are separated where practical, while complete projects keep their styles and assets beside their pages so they continue to work.

1. `01_HTML_Fundamentals` — first page, document structure, inline and relative paths
2. `02_Tables_Forms_and_Cards` — tables, forms, assignments, and cards
3. `03_Layout_and_Responsive_Design` — grid, carousel, media queries, and CSS notes
4. `04_Positioning_and_Animations` — positioning, hover effects, and animation lessons
5. `05_Frameworks` — Bootstrap and Tailwind examples
6. `06_Web_Projects` — CampusAI, Range Rover, portfolio, and conference projects
7. `07_Extra_Practice` — day lessons and additional exercises
8. `08_Java_Tutorial` — Java practice kept separate from the web lessons

Some pages are standalone exercises with styles written inside the HTML. `06_Web_Projects/Portfolio/index.html` still references `styles.css`, which was not present in the project before reorganization.
