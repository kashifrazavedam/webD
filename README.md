# Web Development and Programming Practice

A collection of learning exercises and small projects covering HTML, CSS, JavaScript, and Java. Lessons are grouped by topic and numbered where a learning sequence is useful.

## Contents

- `01_HTML_Fundamentals` — first page, document structure, and paths
- `02_Tables_Forms_and_Cards` — tables, forms, assignments, and cards
- `03_Layout_and_Responsive_Design` — grid, carousel, and media queries
- `04_Positioning_and_Animations` — positioning, hover effects, and animation
- `05_Frameworks` — Bootstrap and Tailwind examples
- `06_Web_Projects` — CampusAI, portfolio, Range Rover, and conference projects
- `07_Extra_Practice` — additional HTML exercises and practice pages
- `08_Java_Tutorial` — Java programming exercises
- `JAVASCRIPT` — JavaScript lessons, DOM exercises, and small projects
- `practice.html` — standalone HTML practice page

## Opening the projects

Open an exercise's HTML file in a browser. For projects with separate stylesheets or assets, keep the directory structure intact; the pages use relative paths to load those files. The portfolio stylesheet is in `06_Web_Projects/Portfolio/styles.css` beside its `index.html` file.
